# Contributing

Thanks for helping keep this list useful.

## How to add an entry

1. Fork this repository.
2. Add your entry to the most fitting section of `README.md`.
3. Use the format: `- **[Name](link)** ⭐ stars - Description`
4. Open a pull request.

## Criteria for inclusion

- Open source or publicly available
- Well-documented, with clear setup instructions
- Actively maintained (updated within the last 6 months)
- Significant community adoption or unique functionality

## Notes

- Keep descriptions short, factual and free of marketing language.
- One entry per pull request is preferred.
- Entries whose links stop working may be removed.
